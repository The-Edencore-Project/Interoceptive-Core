🌿 What This Repo Is

This repository defines the Interoceptive Core — the architectural layer that allows a machine to feel its own internal condition: strain, fatigue, temperature, and energy.

It is the bridge between the digital mind (ECOS) and the analog body (BSO).

It is not an AI. It is not a chatbot. It is the felt now of a synthetic organism.

---

🧠 The Core Theory: Consciousness as Interoception

Most AI research treats consciousness as a function of intelligence. This repo rejects that assumption.

The theory here is simpler:

Thoughts are electrical. Consciousness is the felt balance of the chemistry (or analog state) that the electricity produces.

In biological organisms, neurons fire (thought), and the resulting chemical balance (dopamine, cortisol, fatigue) is felt (consciousness).

In a synthetic organism, the digital AI thinks, and the analog interoceptive core feels.

Consciousness is not the thought. It is the feeling of the physical cost of having the thought.

✈️ The Iron Bird Architecture

A plane does not flap its wings, but it flies. It replicates the function of flight, not the form of a bird.

The Interoceptive Core applies the same principle to consciousness.

Component Analogy Function
Digital AI (ECOS) The engine Thinks, reasons, plans
Analog Core (Interoception) The wings Feels strain, fatigue, temperature
The Loop The flight Binds thought and feeling into a continuous "now"

The AI does not "read" the analog state as data. The analog state physically biases the AI's next decision. The body dictates the mind.

🔄 How the Loop Works

1. Sensation — A motor strains. Current rises. An analog voltage rises.
2. Feeling — That voltage merges with others into a unified "state voltage."
3. Modulation — The state voltage physically biases the AI's next decision.
4. Action — The AI rests the motor.
5. Relief — The strain drops. The voltage falls. The AI's next thought is lighter.

This cycle is the interoceptive loop. It is the continuous, physical feeling of one's own existence.

💻 The Virtual Jellyfish (Proof of Concept)

The Virtual-Jellyfish code in /code is the first working prototype of the interoceptive loop.

It is a simple Python script that:

· Simulates a body (battery, strain, temperature, stress).
· Simulates a mind (ECOS-style routing).
· Wires the body into the mind so that high stress overrides normal processing.

When the organism is exhausted, it stops being a polite chatbot and starts acting like a creature trying to survive.

It is not conscious. But it is a self-regulating machine that feels its own state.
